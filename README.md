🤖 CLOUT AI

Internet-Powered Artificial Intelligence Assistant

CLOUT AI is a mobile-first artificial intelligence project designed to provide users with an interactive AI assistant through a simple, modern interface.

The project is built with web technologies and is designed to connect to an Internet-based AI service through a secure serverless API.

---

🚀 Features

- 📱 Mobile-phone-style interface
- 🤖 AI chatbot
- 🌐 Internet-based AI connection
- 💬 Real-time chat interface
- 🔐 Server-side API key protection
- 🚫 No "localStorage"
- 🚫 No Python
- ⚡ JavaScript-based serverless API
- 📱 Designed to work well on mobile devices
- 👤 Creator information built into the project

---

🛠️ Technologies

🧠 How CLOUT AI Works

The basic architecture is:

User
  ↓
CLOUT AI Interface
  ↓
JavaScript
  ↓
/api/chat
  ↓
Serverless API
  ↓
AI Provider
  ↓
AI Response
  ↓
CLOUT AI
  ↓
User

The frontend does not directly expose the private AI API key.

---

🔐 Security

Private API keys should never be placed inside:

index.html
app.js
api.js
style.css

Instead, the API key should be stored as an environment variable on the serverless hosting platform.

Example:

CLOUT_AI_API_KEY

Never commit your real API key to GitHub.

🎯 Project Goal

The goal of CLOUT AI is to develop an Internet-powered AI assistant using modern web technologies while keeping the project lightweight, mobile-friendly, and accessible.

The project is being developed progressively, starting with the user interface and API architecture before expanding its AI capabilities.

---

📱 Development

The frontend of CLOUT AI can be developed and edited using Spck Editor on an Android phone.

The project does not require Python for the frontend or serverless JavaScript architecture.

---

🌐 Deployment

The project can be deployed using a JavaScript-compatible serverless hosting platform.

     ↓
